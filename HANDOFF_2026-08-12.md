## Working note

Four defects this session shared one shape: **they reported success while doing nothing.** `drop if exp_sens > 1` silently deleting 282 counties. `cairo_pdf` failing as a warning while `ggsave` wrote no file and the script printed "wrote:". A 95-percent match gate passing at 98.1 percent while an entire state rendered blank. `git status` leaving an unremovable `index.lock`.

The fix in each case was the same: **assert the artifact exists and has the shape you expect, rather than trusting the call that produced it.** Every script touched today now does that.

The second recurring shape: **a format was assumed rather than inspected.** That is the exposure defect, and it recurred *inside the fix for the exposure defect* — a defensive `"3133"` clause guarding against a NAICS encoding that had not been looked at, which double-counted Textile and Fabric Finishing Mills in 524 counties. A defensive clause guarding against a format you have not inspected is not defensive. It is a second guess with more confidence attached.
